# AI Travel Planner

An AI-powered travel planning application that creates budget-conscious trips with transport, accommodation, activities, food, shopping, and day-wise itineraries.

## Features

- Budget-based travel planning
- Transport recommendations
- Accommodation recommendations
- Places and activity suggestions
- Food and shopping recommendations
- Day-wise itinerary generation
- Weather and location API integration
- Save and load trip plans
- Export trip plans as JSON

## Tech Stack

- Python
- Geoapify APIs
- Open-Meteo API
- JSON
- Git and GitHub
